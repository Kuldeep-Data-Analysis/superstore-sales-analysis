# Superstore Sales Analysis 📊

## About This Project
Analyzed 9,800 orders of a real retail company 
using Excel and Power BI to find key sales insights.

## Tools Used
- Microsoft Excel
- Power BI Desktop

## What I Analyzed
- Total Sales calculation
- Total Orders count
- Average Order Value
- Maximum and Minimum Sale
- Category wise Sales
- Region wise Sales

## Key Insights
- Technology category has highest sales
- West region is top performer
- South region needs improvement
