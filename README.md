# Superstore Sales Analysis 📊

## About This Project
Real retail company ka 9,800 orders ka 
sales data analyze kiya Excel aur Power BI use karke.

## Tools Used
- Microsoft Excel
- Power BI Desktop

## What I Analyzed
- Total Sales calculation
- Total Orders count
- Average Order Value
- Maximum and Minimum Sale
- Category wise Sales
- Region wise Sales

## Key Insights
- Technology category has highest sales
- West region is top performer
- South region needs improvement
